# Features

## Developer Mode

### GitHub Analysis

* Analyze GitHub profile and repositories.
* Detect programming languages and technologies used.
* Analyze repository activity and contribution history.
* Evaluate project quality based on documentation, structure, and consistency.

### Resume Analysis

* Upload and analyze resumes (PDF).
* Extract technical skills, education, and experience.
* Identify missing or weak sections.

### Portfolio Analysis

* Analyze personal portfolio websites.
* Evaluate project presentation and organization.

### AI Insights

* Generate AI summaries of the developer's profile.
* Highlight strengths and weaknesses.
* Detect skill gaps.
* Suggest improvements.

### Personalized Recommendations

* Recommend projects based on missing skills.
* Recommend technologies to learn.
* Recommend learning resources and certifications.

### Progress Tracking

* Store previous analyses.
* Compare progress over time.
* Display growth trends.

### Dashboard

* GitHub statistics.
* Skills overview.
* AI insights.
* Progress visualization.
